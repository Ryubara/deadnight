# Deadnight

An original round-based co-op zombie survival game, set over one night at a 1958 drive-in theater. Made with Godot
by GDStudio, built by agents.

## Set up

Deadnight lives in a GDStudio workspace beside the kit. Build one with the kit's bootstrap (it clones this repository
and fetches the pinned Godot and Blender):
[GDStudio kit](https://github.com/Ryubara/gdstudio#set-up-a-workspace). Then open `game/project.godot` with the
pinned Godot.

The [docs](https://ryubara.github.io/deadnight/) hold the design and what we learned building it.
